Music Island is a client-side Fabric mod that displays information about the music currently playing on your PC directly in Minecraft using Windows Media Session.

The mod adds:

Track artwork — album/track cover
Song title
Artist
Current time
Playback status
Play/Pause controls
Audio visualizer
Lyrics

All elements are highly customizable, including colors, size, position, visibility, and animations.

Language Support
English and Russian languages.

Requirements
Windows 10 / 11
dont work  Linux\Mac

Music Island uses Windows Media Session and is not tied to Spotify or any specific music service.
